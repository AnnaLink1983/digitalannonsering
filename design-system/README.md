# Designsystem-referens (desktop-only)

Lokal kunskapsbas för ICA Elements som används i desktop-template. Filerna
här är **uppslagsverk** — slå upp när en vy behöver dem, läs inte allt
upfront.

| Fil | När du läser den |
|-----|------------------|
| `components.md` | För att hitta rätt komponent (Core-tabellen räcker oftast) |
| `tokens.md` | För att slå upp en färg, spacing eller radius |
| `PATTERNS.md` | För sammansatta mönster (layout-two-columns, datatabell, sök+filter, dialoger) |
| `WORKAROUNDS.md` | Stub — folded i PATTERNS.md |
| `references/<komp>/api.md` | Innan du använder en specifik komponent |
| `layouts/README.md` | För att hitta en layoutbild som matchar en vy-typ |

Desktop-template använder inte `mb-ica-button-icon-vertical`,
`mb-ica-sorting-drop-down`, `mb-ica-transition-slide` (mellan vyer) eller
`mb-ica-transition-panel`. Se `components.md` → "Avlägsnade i desktop-template"
för alternativ.

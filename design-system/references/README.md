# Komponentreferenser

Screenshots från Storybook (storybook.minbutik.ica.se) som visar hur ICA Elements-komponenter ser ut, med varianter och states synliga i bilderna.

Claude Code ska läsa dessa bilder för att matcha utseende vid kodgenerering.

## Mappar

Varje mapp motsvarar en komponent. Lägg screenshots direkt i mappen.

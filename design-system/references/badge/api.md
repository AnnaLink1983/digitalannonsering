# mb-ica-badge

Badge/notis-indikator som visar en siffra eller markering.

## När ska du använda badge?

- Notisräknare på ikoner (t.ex. antal olästa)
- Statusmarkering på navigation eller knappar

## Attributes

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `count` | number | — | Siffra att visa i badgen |

> **OBS:** Den här filen är en stub — fullständig API-dokumentation saknas.
> Verifiera alla props, events och slots mot Storybook innan du använder komponenten.

## Kodexempel

```html
<mb-ica-badge count="3"></mb-ica-badge>
```

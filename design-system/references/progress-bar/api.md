# mb-ica-progress-bar

Framstegsmätare som visar hur långt en process har kommit.

## När ska du använda progress-bar?

- Visa framsteg i ett flerstegsflöde
- Laddindikatorer med känt procentvärde

## Attributes

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `value` | number | 0 | Aktuellt värde (0–100) |
| `max` | number | 100 | Maxvärde |

> **OBS:** Den här filen är en stub — fullständig API-dokumentation saknas.
> Verifiera alla props, events och slots mot Storybook innan du använder komponenten.

## Kodexempel

```html
<mb-ica-progress-bar value="65"></mb-ica-progress-bar>
```
